# FeelFit 24

Website for Feel Fit 24 — a 24/7 gym in Block A, Satellite Town,
Gujranwala. Separate training areas for men and women, personal training,
fat loss, cardio and strength coaching.

**Live site:** https://ff24feelfit.com/

## About the site

- Static single-page site (`index.html` plus `assets/`) — no build step
- Gym schema (ExerciseGym JSON-LD), Open Graph / Twitter cards, sitemap
  and robots files included
- Bookings and enquiries route through the gym's phone and WhatsApp

## Run locally

Serve the folder with any static server:

```bash
npx serve .
```
